# Mac and iPhone Widgets Implementation Plan

> Execute inline, task by task, with verification at each boundary.

**Goal:** Native Mac and iPhone usage widgets backed by private iCloud summaries.
**Architecture:** Existing Mac monitoring → typed summary → App Group cache and optional private CloudKit record → iPhone app/widget. Shared SwiftUI widget presentation.
**Tech Stack:** Swift, SwiftUI, WidgetKit, CloudKit, XcodeGen, SwiftPM tests.
**Spec:** ../specs/2026-09-07-widgets.md

## Constraints
- macOS 14+ and iOS 17+ for widget hosts; existing standalone Mac baseline unchanged.
- No credentials/raw provider responses in widget data; private CloudKit only.
- Explicit unknown/stale/error states. Widget updates follow OS budgets.
- No paid enrollment, production schema, or physical-device success inferred.

## Execution
- [x] Define `UsageSnapshot`, `ProviderUsage`, `UsageMetric`, `UsageHealth` in `apple/Shared/UsageSnapshot.swift`. Validate schema, bounds, duplicate IDs and timestamps on decode. Test round-trip, malformed/unsupported data, clock skew, stale health, quota semantics and ranking with `swift test --package-path apple`.
- [x] Implement atomic `SnapshotFile` cache and platform `WidgetStore` App Group storage in separate Shared files. Preserve source time on sync. Test corrupt and atomic replacement cases.
- [x] Implement private `CloudSnapshotStore` single-record fetch/save, serial Mac publishing and retry throttling. Use deterministic record ID, bounded payload and generic actionable errors. Do not persist raw error descriptions.
- [x] Create native WidgetKit small/medium/large and Lock Screen timelines and shared views in `apple/Widgets`. Include an explicit stale transition entry and request refresh in 30 minutes. No fixture data outside previews.
- [x] Integrate Mac publisher at successful/failed monitoring results under `WIDGET_HOST`, retaining previous successful values without refreshing their timestamps. Add opt-in menu action and build the original app as a signed-capable macOS app target with embedded widget.
- [x] Create iPhone companion with manual iCloud sync, last-update and recovery states. Use shared app-group cache; widget performs cloud refresh only after sync is enabled in companion.
- [x] Add XcodeGen four-target project and entitlements/configuration files. Generate and build macOS + generic iOS Simulator with signing disabled. Build/run iPhone simulator companion; execute shared and existing Mac tests.
- [x] Document exact enrollment/signing/schema/device steps and remaining live verification. Commit implementation on `codex/apple-widgets`, leaving personal release untouched until device signing is available.
